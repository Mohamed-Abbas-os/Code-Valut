# CodeVault Frontend

Basic HTML/CSS/JavaScript frontend for uploading and viewing C programs.

## Files

- `index.html` — main page
- `style.css` — styling
- `script.js` — sample programs, viewer, and frontend-only file selection
- `.github/workflows/deploy.yml` — automatic GitHub Pages deployment

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Make sure the branch is named `main`.
4. Go to Settings → Pages.
5. Under Build and deployment, select GitHub Actions.
6. Push/update the repository. The workflow will deploy the site.

This is a frontend-only prototype. Files selected in the browser are not permanently stored yet.
